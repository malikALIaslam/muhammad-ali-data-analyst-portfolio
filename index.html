MACHINE LEARNING VIEW PROJECT ↗
MACHINE LEARNING / PREDICTIVE ANALYTICS

iPhone Resale Price Prediction

An end-to-end machine learning project developed to predict iPhone resale prices using device condition, model, storage, battery health, and market-related features. The project covers data cleaning, exploratory data analysis, preprocessing with OneHotEncoder, model comparison, cross-validation, hyperparameter tuning, evaluation, feature importance, and prediction on new data. Linear Regression, Decision Tree, and Random Forest models were compared, with Random Forest achieving a 97.8% R² score.
